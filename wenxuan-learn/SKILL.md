# Learn Skill — 选题深挖学习引擎

## 核心理念

**学习是为了输出。一切都为让用户毫无压力地写出一篇长文而服务。**

不是出报告，是告诉用户学什么、看什么、怎么做。每个知识点都标注"在文章里能怎么用"，不是展示知识，是武装写作者。

## 冰山理论

选题只是冰山尖（20%），80%沉在水底。写之前必须先把水底知识挖出来，学透，再动笔。

判断标准：**AI认为这件事已经详尽到足够一个完全不懂的小白通过学习这篇文档也能成为一个小专家。**

## 双轴分析法（v2.0 新增 · 可选骨架，源自 hv-analysis）

**触发条件**：当选题是"产品/公司/技术/人物/概念"且文轩想"心里有数"时，**推荐用双轴**。普通写文章场景不必启用。

> **纵向追时间深度，横向追同期广度，最终交汇出判断。**

**纵轴** = 沿时间轴还原"它从哪来、怎么演变、现在长啥样"（起源/诞生/演进/决策/阶段划分）。
**横轴** = 在当下截面上与竞品/同类对比（核心竞品/用户视角/生态位/趋势）。
**交汇** = 用纵轴解释横轴里看到的现象，产出别人没讲过的新判断（优势/劣势的历史根源 + 未来三剧本）。

**双轴替代关系**：双轴的纵轴 = 原冰山 B 层（历史演变）的升级版；横轴 = 原冰山 C 层（竞品）的升级版；其他冰山层（A/D/F）成为**搜索指南针**，不独立成节。

**主题类型判断**（第 1 步必做）：主 agent 智能判断主题类型（产品/公司/技术/人物/现象/概念），用于决定是否启用双轴骨架。

**4 类研究对象适配（v2.0 新增 · 来自 hv-analysis）**：核心原则不变（纵向追时间深度，横向追同期广度），但侧重点不同——

| 类型 | 纵轴重点 | 横轴重点 |
|------|---------|---------|
| **产品** | 版本迭代、技术路线演变、用户增长曲线、关键产品决策 | 功能对比、性能对比、用户体验、定价 |
| **公司** | 创始团队、融资历程、战略转向、组织变革、关键人事变动 | 商业模式差异、市场份额、营收对比、组织架构差异 |
| **概念**（技术范式/商业模式/文化现象）| 概念起源（谁提出、基于什么理论/需求）、如何流行、经历了哪些争论和演变 | 与相近概念的区别、各自适用场景、不同阵营的论证 |
| **人物** | 个人经历、职业轨迹、关键决策、成长曲线、公开言论变化 | 与同领域其他人物对比（做事方式、风格、成就、影响力、路线选择差异） |

**弹药包 → 报告升级（v2.0 升级）**：当文轩跑的是"产品/公司/技术/人物/概念"型深度研究时，**最终交付物是研究报告，不是写作弹药包**。篇幅 **10000-20000 字硬约束**，结构走下面 4 章模板：

```
封面页

一、一句话定义
[用一句话说清楚这个东西是什么]

二、纵向分析：从诞生到当下
[完整的纵向叙事 + 决策逻辑还原]

三、横向分析：竞争图谱
[A/B/C 三场景判断 + 竞品对比 + 用户视角 + 生态位 + 趋势]

四、横纵交汇洞察
[5 必答 + 三剧本推演]

五、信息来源
[所有引用的来源列表 + 访问时间]
```

**横纵交汇 5 必答 + 三剧本（v2.0 来自 hv-analysis · 报告核心）**：
1. **历史如何塑造了当下的竞争位置**：纵向中的哪些决策/事件，决定了它今天在横向中的位置？
2. **竞品的纵向对比**：把主要竞品也放到时间线上看，它们的起源和演变路径有什么不同？如何导致今天各自的特点？
3. **优势的历史根源**：今天的每个核心优势，能追溯到历史上的哪个节点/决策？
4. **劣势的历史根源**：今天的每个核心劣势，能追溯到哪个历史决策？当初的"好决策"有没有变成今天的包袱？
5. **未来三剧本推演**：
   - **最可能剧本**：基于当前轨迹最自然的走向
   - **最危险剧本**：什么变量一旦出现会彻底改变格局
   - **最乐观剧本**：所有有利变量同时兑现的天花板
   - 每个剧本必须有逻辑支撑，不是拍脑袋

**普通写文章场景**仍走原"弹药包"模板（速览/关键词弹药/正反竞奇×冰山/必学精选/事实核查剔除/选题脉络指引），不强制字数、不走 4 章报告。**判断口径**：文轩说"做研究/发给别人看/留存归档" → 报告；"为写文章挖料" → 弹药包。

## 必选 PDF 输出（v2.0 新增 · 来自 hv-analysis）

**前置环境配置**（必须先做）：

```bash
# 1. 找到你的 Python 解释器

# 注意：
# - weasyprint 依赖系统库：Windows 需装 GTK3 runtime；macOS brew install cairo pango；Linux apt install libcairo2 libpango-1.0-0

# 4. 验证依赖

# 或
python -c "import fpdf, markdown; print('OK')"
```

**运行转换**（主版本，weasyprint）：

```bash
# 从 wenxuan-learn 根目录
python scripts/md_to_pdf.py "选题学习包-<选题名>.md" "选题学习包-<选题名>.pdf" --title "选题学习包：<选题名>" --author "文轩"

- 第一个 H1 会自动提取为封面标题，正文不重复

**必选策略**：每次跑完 wenxuan-learn 都必须同步产出一份 PDF，与 .md 同名同目录。.md 是过程中间产物，PDF 才是最终交付物（发给别人看/留存归档/做成研究报告都靠它）。

## 正反竞奇框架

每一个冰山层都从四个视角深挖：

| 视角 | 含义 | 搜索策略 |
|------|------|----------|
| **正** | 官方说法、主流解读、产品文档、支持论据 | 搜官方/权威/正面解读 |
| **反** | 评价、质疑观点、批评者、反对论据、失败案例 | 搜批评/质疑/负面评价 |
| **竞** | 同生态位、同属性、同用户的竞争同类 | 搜同类产品/内容/方案，标注核心差异 |
| **奇** | AI自动联想跨领域，尽可能反直觉联系 | 联想3-5个跨领域方向，必须有新意，没有就跳过 |

## 冰山分层

| 层 | 内容 | 优先级 |
|----|------|--------|
| **A层** 技术/产品原理 | 选题背后的技术/产品运作机制 | 必须 |
| **B层** 历史演变 | 怎么出现的、为什么发生、如何演变 | 必须 |
| **C层** 竞品/案例 | 竞品详细情况、同类案例、对标分析 | 必须 |
| **D层** 痛点 | 目标读者到底在挣扎什么 | 必须 |
| **E层** 心理学底层 | — | **跳过** |
| **F层** 数据支撑 | 必须真实可靠有来源，也按正反竞奇组织 | 必须 |

## 搜索规则

- **来源比例**：80%英文互联网 + 20%中文互联网
- **质量门槛**：A 类一手信源为主（详见 `references/source-quality.md`）
- **搜索轮数**：至少20轮WebSearch/WebFetch调用，不设上限，搜到AI判断"够详尽"为止
- **搜索策略**：发散式搜索→挖根→找关键词→再搜索→直到弄懂
- **第2步概览**：发散式搜索为重点，看名人/做过的事/概念运作方式，找关键词后再进一步搜索
- **第3步聚焦**：每个论点必须配上论据和出处，具体说明，配上链接
- **奇层联想**：3-5个跨领域方向，必须反直觉有新意（如：PUA→动物行为学→生物学发现），没有就跳过
- **事实核查（强约束）**：不实数据或不存在的引用不能进入弹药包。每条事实声明必须有出处或可验证链接，找不到的直接剔除
- **arxiv 强约束（学术类研究对象必查，v2.0 新增 · 来自 hv-analysis）**：选题涉及学术概念/算法/AI 模型/技术范式时，必须用 arxiv API 查论文：`curl -s "https://export.arxiv.org/api/query?search_query=all:关键词1+AND+all:关键词2&max_results=10"`，或 WebFetch 同一 URL。找到关键论文后再用 WebFetch 读 `https://arxiv.org/abs/论文ID` 拿细节

> **信源分级**：A 类（官方/GitHub/论文/产品本体，必查）→ B 类（权威媒体/大佬博客，需交叉）→ C 类（社区/社媒，只作辅证）。详见 `references/source-quality.md`。

## 五步流程（一口气跑完）

### 第1步：明确问题与边界

用户通常已经想好要讲什么，不需要AI帮忙选方向。直接根据用户给的选题开始搜索。

如果选题过于模糊（如"AI搞钱"而非"anti-pua技能"），先帮用户缩小范围，给出3-5个细分方向让用户选择，然后锁定一个继续。

### 第2步：发散式概览探索

核心动作：
1. 用选题关键词做首轮广搜（WebSearch 5-8轮）
2. 从搜索结果中提取5-8个核心术语/子关键词
3. 用每个子关键词再做2-3轮深搜（WebSearch + WebFetch）
4. 识别名人/关键人物、做过的重要事、概念的具体运作方式
5. 继续发散：搜索选题所在领域的关联概念、相邻领域、对立概念
6. 持续搜索直到AI判断：小白读完这篇文档也能成为小专家

输出（内部暂存，不展示给用户）：
- 核心术语列表（5-8个）+ 一句话解释
- 名人/关键人物列表 + 他们做过的事
- 概念运作方式简述
- 发散关联概念列表

### 第3步：正反竞奇×冰山深挖

对A/B/C/D/F每一层，从正/反/竞/奇四个视角搜索：

每个视角的搜索动作：
1. 构造针对性搜索查询（正方关键词、反方关键词、竞品关键词、奇联想关键词）
2. WebSearch 2-4轮搜索
3. WebFetch 1-3轮深读高质量结果
4. 提取核心论点+论据+出处+链接

输出要求：
- 每个论点必须配有论据和出处
- 不设上限，有价值就呈现，但必须真的有价值
- 奇层：联想3-5个跨领域方向，必须有新意，没有就跳过
- F层数据：必须真实可靠有来源
- **每条事实声明必须通过核查**（见搜索规则），未通过的不进弹药包

### 第4步：必学精选

从所有搜到的内容中精选最有写作价值的内容：

每条精选必须包含：
- 链接
- 核心内容摘要（2-3句话）
- 你能从中学到什么
- 为什么你要学它
- 在文章里能怎么用

不多但精——每条都有明确的写作价值标注。

## 搜索执行细节

### 搜索查询构造

**正方搜索**：
- `[选题] official documentation`
- `[选题] mainstream explanation`
- `[选题] how it works`
- `[选题] creator/founder statement`

**反方搜索**：
- `[选题] criticism problems`
- `[选题] why [选题] failed/bad`
- `[选题] skeptic opinion`
- `[选题] negative review`

**竞品搜索**：
- `[选题] alternatives competitors`
- `[选题] similar products/tools`
- `[选题] vs [竞品名] comparison`
- `[选题] same category tools`

**奇层搜索**：
- `[选题核心概念] in [跨领域] biology/sociology/anthropology/etc`
- `[选题] unexpected connection`
- `[选题核心概念] animal behavior/neuroscience/etc`
- `[选题] unconventional perspective`

### 搜索质量筛选

每轮搜索后筛选标准：
1. 来源是否权威/可信（官方文档、学术论文、知名媒体、领域专家）
2. 内容是否包含具体论据（不只是观点，有数据/案例/实验支撑）
3. 是否与选题直接相关或有明确的跨领域连接
4. 是否提供新的视角/信息（不重复已搜到的内容）

不符合标准的直接跳过，不呈现。

## 并行子 agent 策略（借鉴 hv-analysis，2026-06-14 融合）

wenxuan-learn 选型场景是「深挖一个选题」，比 wenxuan-research 的全景扫描小。**但正反竞奇×冰山 A/B/C/D/F = 4×5 = 20 个搜索槽位**，单 agent 串行跑下来要 1-2 小时。引入子 agent 是为了「主题间独立的部分并发」提速 3-4 倍。

**分工建议**（按选题复杂度弹性派）：

| 选题复杂度 | sub-agent 数 | 分工 |
|----------|------------|------|
| **小型**（单点功能 / 单一事件）| 0，主 agent 串行 | — |
| **中型**（产品/工具型选题）| 2 | 视角组 A（**正+竞+奇**） + 视角组 B（**反+F 数据**） |
| **大型**（行业现象 / 跨领域选题）| 4 | 视角组 A（**正+竞**） + 视角组 B（**反+F 数据**） + 视角组 C（**奇层跨领域**） + 视角组 D（**冰山 B/D 层**） |

**主题选择原则**：
- 同一个搜索主题（关键词组合）只能由一个 sub-agent 跑，避免重复
- 主 agent 在 sub-agent prompt 头部注入**关键词黑板**（本轮已用关键词 + 已见 URL 清单）
- sub-agent 跑完只回写新增信息，重复内容不写

**主 agent 汇总阶段**（关键步骤，不能省）：
1. **去重**：合并 N 个 sub-agent 的搜索结果
2. **冲突调和**：反方 + 正方对同一事实有不同说法时，标注为"争议"留到第 4 步让用户判断
3. **奇层把关**：跨领域联想必须由主 agent 最终拍板，sub-agent 容易乱联想
4. **事实核查统一执行**：每条事实声明的核查在主 agent 层做，不分散到 sub-agent

**子 agent 联网工具指引**（嵌入每个 sub-agent prompt）：

> 你需要联网获取信息。使用以下工具：
> - **WebSearch**：用于搜索发现信息来源，获取摘要和关键词结果
> - **WebFetch**：当已知具体URL时，用于从页面定向提取内容
> - 搜索策略：先用WebSearch发现信息来源和线索，找到具体URL后用WebFetch深入提取
> - 多次搜索、多个关键词组合，不要只搜一次就放弃
> - 一手来源优于二手来源：官方博客 > 权威媒体原创报道 > 转载/聚合
> - 学术类研究对象必查arxiv：`curl -s "https://export.arxiv.org/api/query?search_query=all:关键词1+AND+all:关键词2&max_results=10"`，或用WebFetch访问同一URL

prompt 要描述目标（"获取""调研""了解"），不要用暗示具体手段的动词（"搜索""爬取"），让子 agent 自主判断最佳获取方式。

## 选题方向锁（v1.1 新增 · 防止越搜越散）

20+ 轮搜索下来，写作者最容易迷失——"我刚开始想写 A，搜着搜着变成 B、C、D，最后写出来 D 跟开头 A 没关系"。

**机制**：
1. **第 1 步定锁**：选题确定后（第 1 步末尾），主 agent 写一段「**选题方向锁声明**」（200-300 字），包含：
   - 核心读者（谁）
   - 核心冲突（这个选题的张力点）
   - 边界（不写什么）
   - 期待的读者收获（拿走后能做什么）
2. **第 2/3 步中检查**：每轮搜索前，主 agent 用 5 秒回看锁声明，回答"这一轮搜的关键词还在锁声明的边界内吗？"
3. **越界时回头问用户**：如果发现某个方向很重要但超出锁声明边界，**记录到"边界外发现"附录**，不纳入弹药包主流程

**示例**（以"AI 工具搞钱"为锁）：
> **方向锁**：面向想用 AI 工具副业变现的普通职场人；核心冲突是"信息爆炸但实战指南稀缺"；不写"AI 是不是泡沫""AI 取代论"；读者拿走的是 3 个可立刻动手的副业路径 + 各自的难度/收益/坑点。
>
> 第 3 步搜到"AI 对就业市场的宏观影响"——**越界**，写入「边界外发现」附录，不进弹药包。

## 写作后验反馈环（v1.1 新增 · 跟 writer 真正闭环）

wenxuan-learn 输出的弹药包交给 wenxuan-writer 后，**文轩写完文章回头看一眼能否验证弹药质量**。机制：

**反馈触发**：用户完成 wenxuan-writer 输出后，问一句"这次弹药包里哪些真的用上了？哪些其实是死重？"

**反馈处理**：
- **死重**（写了没用的）→ 在弹药包对应位置标记「[writer 反馈：未用]」并存档，让 learn 下次生成时跳过同类内容
- **核心命中**（贯穿全文反复用）→ 在第 4 步「必学精选」中给更高权重，类似"alpha 信号"
- **结构性补强**（"要是当时有 XX 这条就好了"）→ 沉淀到 references/writer-backlog.md，下次新选题自动调取

**不要让反馈变成负担**：默认不强制问，只在用户主动提时才走反馈环。

## 质检清单（v2.0 新增 · 14 条 · 来自 hv-analysis）

报告交付前自检，**逐条勾选不通过就重做**：

- [ ] 纵轴是叙事故事体？有因果逻辑和时代脉络？不是年表流水账？
- [ ] 创始人/发起者的背景和动机有足够深度？
- [ ] 每个关键节点都展开写了，没有为压缩跳过重要细节？
- [ ] 决策逻辑有还原（"为什么选 A 不选 B"）？不只是"发生了什么"？
- [ ] 横轴的竞品场景判断正确（A/B/C）？竞品分析够深？
- [ ] 用户口碑部分引用了真实用户的声音？不只是官方宣传？
- [ ] 横纵交汇产出了新的判断，不是前面内容的缩写版？
- [ ] 未来推演的三个剧本都有逻辑支撑？
- [ ] 写作风格有节奏感、有可读性？不是冷冰冰的咨询报告？
- [ ] 没有触犯绝对禁区里的任何一条？
- [ ] 所有关键事实标注了信息来源？
- [ ] 搜不到的信息诚实标注了"暂缺"，没有编造？
- [ ] PDF 排版美观、结构清晰、可读性好？
- [ ] 总字数在 10000-20000 字（报告）/ "够详尽"（弹药包）？

## 流程总结

```
用户触发 wenxuan-learn
→ 第1步：明确选题边界 + 方向锁声明
→ 第2步：发散搜索至少20轮 → 建立概念地图（小型选题不派子 agent）
→ 第3步：正反竞奇×A/B/C/D/F
  - 中型/大型选题：派 2-4 个 sub-agent 并行（关键词黑板去重）
  - 主 agent 汇总：去重 + 冲突调和 + 奇层把关 + 统一事实核查
→ 第4步：精选最有写作价值的内容 → 标注文章用法
→ 第4.5步（弹药包模式）：AI 引导性问题 → 用户自由写 → AI 评判
→ 第5步（报告模式）：双轴骨架 → 10000-20000 字研究报告 + 必出 PDF
→ writer 输出后：可选触发反馈环，更新 references/writer-backlog.md
→ 输出选题学习包 → 存到 `D:\path-to-wealth-freedom\内容\灵感\选题学习包\选题学习包-<选题名>.md`（弹药包）/ `[研究对象]_横纵分析报告.pdf`（报告）
→ 如果用户不输出 → anti-pua 当场出手
```
