# humanlize 心法 Prompt 注入片段

> 用途：wenxuan-translate 主 agent 过程注入 + 人味 sub-agent 后置复检
> 心法核心：人写的字背后站着一个具体的人，他在具体的位置上，付出过具体的代价。

---

## 三件套：位置 / 代价 / 手迹

### 1. 位置（Where & When）

原文写作者**在什么语境下**写这段话？

| 维度 | 问自己 |
|---|---|
| 行业 | 是技术圈 / 创投圈 / 学术界 / 自媒体 / 政商圈？ |
| 时间 | 是什么时候写的？最近有什么大事件影响他？ |
| 情绪 | 写这段时他在什么状态？（兴奋/焦虑/愤怒/平静/调侃） |
| 受众 | 他写给谁看？写给同行看 / 写给大众看 / 写给老板看？ |

**翻译时**：译文要让中文读者也能感受到"这是一个 30 岁的技术 VP 在 2024 年某个产品发布后第二天写的"——具体的位置、具体的人。

### 2. 代价（What's at stake）

原文付出了什么努力 / 承担了什么风险 / 放弃了什么？

| 维度 | 问自己 |
|---|---|
| 时间成本 | 他为写这段话花了多少时间？ |
| 关系风险 | 他敢说这话，会不会得罪人？会不会失去什么机会？ |
| 认知门槛 | 他要解释得多深才能让读者懂？ |
| 利益权衡 | 他放弃了什么简洁性 / 准确性 / 礼貌？ |

**翻译时**：译文中保留原文的"敢于承担"——不替他圆滑、不替他客气、不替他偷懒。

### 3. 手迹（Voice Fingerprint）

原文的"语气指纹"是什么？

| 类型 | 特征 | 翻译时怎么保留 |
|---|---|---|
| **讽刺** | 用反话 / 反问 / 夸张 | 中文也得讽刺，必要时加"啧""吧""呢" |
| **克制** | 短句 / 留白 / 不说破 | 译文也用短句，**不要补全隐含意思** |
| **直白** | 一句一意思，不绕弯 | 译文也别绕 |
| **调侃** | 玩梗 / 双关 / 谐音 | 必要时加中文同义梗，**找不到就直译加注** |
| **正式** | 严谨 / 用大词 / 不口语 | 译文保持正式 |
| **学术** | 引用 / 术语 / 客观 | 译文保持学术 |
| **口语** | 短句 / 语气词 / 重复 | 译文也用口语 |

**反例（AI 翻译腔）**：
- 原文 "This is a really bad idea." → 译文 ❌ "这是一个相当不智的决策"
- 正确 ✓ "这主意真烂。"

## 反 AI 味 Checklist（人味 sub-agent 后置复检用）

AI 味识别清单，适配中文：

### 词汇层面
- ❌ "值得注意的是" / "综上所述" / "不难发现" → 删
- ❌ "赋能" / "抓手" / "打造闭环" / "全方位" → 删
- ❌ "在当今...的时代" / "随着...的不断发展" → 删
- ❌ "本质上" / "换句话说" / "说白了" → 少用
- ❌ "首先...其次...最后"（工整对仗）→ 拆散

### 句式层面
- ❌ 长定语前置（"作为一家专注于...的领先企业"）→ 重排
- ❌ 工整对仗（"不仅...而且..." 连续用）→ 拆
- ❌ "被"字句滥用（"被认为""被称作"）→ 改主动
- ❌ "通过...的方式" 啰嗦 → 删

### 内容层面
- ❌ 空洞概括（"具有重要意义"）→ 用具体细节
- ❌ "智慧感"开头（"我们应该思考..."）→ 删
- ❌ 平铺直叙不带语气 → 加原文的语气指纹

### 修辞层面
- ❌ 过度工整 → 允许不规则
- ❌ 全是书面语 → 允许口语
- ❌ 一点个人痕迹都没有 → 允许原文的小情绪

## 双重注入策略

**第一重（主 agent 过程注入）**：
在主 agent 翻译时，prompt 头部就带这 3 段：
1. 核心心法
2. 三件套提醒（位置/代价/手迹）
3. 反 AI 味 checklist 摘要

**第二重（人味 sub-agent 后置复检）**：
翻译完成后，人味 sub-agent 拿到完整心法 + 完整 checklist，对主 agent 译文做**第二轮人味审校**。发现残留翻译腔 → 修订。

**为什么双重**：
- 过程注入让主 agent **从一开始就不写 AI 腔**（治本）
- 后置复检**查漏补缺**（治标）
- 双重保险，慢一点但质量门最强

## AI 味 3 维分类（人味 sub-agent 用）

识别 AI 翻译腔的 3 个维度，命中任何一个即扣分。

### 维度 1：词汇 AI 味（Vocabulary Smell）

| 类别 | 高频 AI 词 | 处理 |
|---|---|---|
| **空话套话** | 值得注意的是、综上所述、不难发现、显而易见 | 全删 |
| **官方黑话** | 赋能、抓手、打造闭环、全方位、立体化 | 全删 |
| **时代套话** | 在当今...的时代、随着...的不断发展、在这个快节奏的 | 全删 |
| **伪深刻** | 本质上、换句话说、说白了、其核心在于 | 慎用 |
| **工整对仗** | 首先...其次...再次...最后（连续 4 段）| 拆散 |
| **学术化** | 具有重要意义、发挥着关键作用、为...奠定基础 | 重写 |

### 维度 2：结构 AI 味（Structure Smell）

| 类别 | AI 结构特征 | 处理 |
|---|---|---|
| **长定语前置** | "作为一家专注于...的领先企业，我们..." | 重排到句末 |
| **连环不仅** | 连续 3 段"不仅...而且..." | 拆成短句 |
| **被字句滥用** | "被认为""被称作""被广泛使用" | 改主动 |
| **通过...的方式** | "通过加强 X 的方式来实现 Y" | 删 8 个字 |
| **空洞概括** | 段落结尾来一句"具有重要意义" | 用具体细节替换 |
| **智慧感开头** | "我们应该思考..."、"我们需要认识到..." | 直接删 |

### 维度 3：语气 AI 味（Tone Smell）

| 类别 | AI 语气特征 | 处理 |
|---|---|---|
| **全程平铺** | 通篇无起伏、无情绪、无小幽默 | 找回原文的语气指纹 |
| **过度正式** | 把口语翻成书面语（"cool" → "具有创新性的"）| 还原原文的口语感 |
| **全程理性** | 通篇"分析""论证""阐述"，无情绪词 | 加回原文的"我""你""我们" |
| **零个人痕迹** | 通篇没有"我""你"等主语 | 加回原文的主语人称 |
| **完美工整** | 全文对仗、句式整齐、无一句不规则 | 允许一句口语打破 |

### AI 味 3 维评分

| 维度 | 0 分（无 AI 味）| 1 分（轻微）| 2 分（重度）|
|---|---|---|---|
| **词汇** | 0 个 AI 词 | 1-3 个 AI 词 | 4+ AI 词 |
| **结构** | 0 个 AI 句式 | 1-2 个 AI 句式 | 3+ AI 句式 |
| **语气** | 与原文语气类型一致 | 轻微偏差 | 完全偏离 |

**及格线**：3 个维度合计 ≤ 2 分（即最多 1 维 2 分，或 2 维各 1 分）。
**不及格**：3 维合计 ≥ 3 分 → 打回主 agent 重译。

### 实用识别口诀

> **AI 翻译腔 = 词汇空 + 结构整 + 语气平**。
>
> 反过来说，**人味译文 = 词汇实 + 结构活 + 语气真**。
