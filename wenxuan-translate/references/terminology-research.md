# 术语研究方法

> wenxuan-translate 事实核查 + 溯源 sub-agent 用的术语研究方法。
> 主 agent + 2 个并行 sub-agent 协同思路（语境研究 sub + 标准译法 sub）。

---

## 核心思路

**翻译中遇到"陌生/有歧义"的术语**，先研究再下笔。

| 阶段 | 动作 | 工具 |
|---|---|---|
| **识别** | 主 agent 标出"高风险术语"清单 | 主 agent 自行识别 |
| **并行研究** | 派 2 个并行 sub-agent：一个查"原文语境用法"，一个查"中文标准译法" | WebSearch + WebFetch |
| **决策** | 主 agent 综合 2 份研究，决定译法 | 合并 → 决策 |
| **沉淀** | 写入 `references/terminology-glossary.md`，下次复用 | 文件持久化 |

---

## 高风险术语识别

主 agent 翻译时，对每个术语判断"是否高风险"：

| 风险级别 | 类型 | 处理 |
|---|---|---|
| **高** | 行业专有名词（如 "transformer" 在 AI 语境）| 必查 → 写入术语表 |
| **高** | 新造词（如 "vibe coding"）| 必查 → 写入术语表 |
| **中** | 多义词（如 "agent" 在不同行业不同意思）| 必查 → 标注语境 |
| **中** | 文化梗（"elephant in the room"）| 必查 → 文化差异标注 |
| **低** | 通用词（如 "system" / "user"）| 不查 → 用通用译法 |
| **低** | 已经在术语表里 | 不查 → 用统一译法 |

## 并行研究 prompt 模板

### 术语 sub-agent 1：原文语境用法

```
你是 wenxuan-translate 的"原文语境"研究 sub-agent。

任务：研究英文术语 "<术语>" 在原文上下文中的用法。

步骤：
1. 在原文上下文中找这个词的用法
2. 搜 WebSearch 找这个词在 [行业] 领域的标准用法
3. 输出：
   - 原文用法：[原文中的语境]
   - 行业标准用法：[行业常见翻译]
   - 建议译法：[中译]
   - 置信度：[高/中/低]

字数：<300 字以内
```

### 术语 sub-agent 2：中文标准译法

```
你是 wenxuan-translate 的"中文标准译法"研究 sub-agent。

任务：研究英文术语 "<术语>" 在中文语境中的标准译法。

步骤：
1. 搜 WebSearch 找中文资料中这个词的译法（"术语 + 中文译法"）
2. 找中文权威来源（学术论文/官方文档/技术博客）
3. 输出：
   - 中文标准译法：[最常见的中译]
   - 译法历史：[这个译法怎么来的]
   - 替代译法：[其他可能译法]
   - 置信度：[高/中/低]

字数：<300 字以内
```

---

## 主 agent 决策流程

拿到 2 份研究后：

1. **置信度高 + 一致** → 直接用
2. **置信度高 + 冲突** → 主 agent 自行判断，记录决策到 F4
3. **置信度中** → 主 agent 自行判断
4. **置信度低** → 标"待核实"留到 F8 人工复检

## 不做术语研究的情况

为避免过度研究浪费时间，**下列情况直接用通用译法**：

| 类型 | 通用译法 |
|---|---|
| 常见动词 | 做 / 说 / 想 / 知道 / 看到 |
| 常见名词 | 系统 / 用户 / 团队 / 项目 |
| 常见形容词 | 好 / 坏 / 大 / 小 / 重要 |
| 已收录在术语表的 | 直接用 |

**触发研究**：仅当术语满足"高/中风险"级别。
