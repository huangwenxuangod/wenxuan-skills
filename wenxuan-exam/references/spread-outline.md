# 传播大纲

阶段 ⑤ 后半。**只取材于 02 证据卡与 03 分析笔记**，不允许引入新事实。时间可调，结构不调。

## 3–5 分钟结构

| 段 | 时长 | 内容 | 硬约束 |
|---|---|---|---|
| 抽题与悬念 | 0:00–0:15 | 抽到什么、我原本以为是什么 | 必须来自 00 选题卡里**用户自己写的研究前判断** |
| 为什么值得研究 | 0:15–0:45 | 一个具体情境说明不懂它会付出什么 | 情境要具体到场景，不要"在这个时代" |
| 关键发现 | 0:45–2:00 | 只讲 2–3 个机制或证据 | 每条标证据卡编号 |
| 认知反转 | 2:00–3:00 | 原来哪里错了、哪个反例改变了判断 | 反转必须真实发生过（03 里有记录），**不许制造** |
| 独立结论 | 3:00–4:00 | 成立条件、适合谁、还不知道什么 | 必须含边界句与未知句 |

## 小红书图文版（可选）

- 第 1 页：结论前置的**问题**（不是答案），配"我以为 vs 我查完发现"。
- 第 2–6 页：一张证据卡一页，只放原文摘录 + 出处。
- 第 7 页：边界与未知。
- 末页：三个可迁移的提问方法（教方法，不教结论）。

## 每段必须写清的字段

```markdown
### 段 3 · 关键发现 2（0:45–2:00）
- 讲什么：<一句话>
- 依据：证据卡 E4、E7
- 画面：<软件界面截图 / 机制图 / 对比表 / 口播>
- 口径风险：<这个数字的条件，口播里怎么交代>
- 不说什么：<容易被误读成绝对结论的表述，明确排除>
```

## 禁止项

- 不给结论加"一定""必然""彻底改变"。
- 不把单一来源说成"业内共识"。
- 不虚构戏剧性反转；如果研究过程没有反转，就如实说"我原来的判断基本没崩，但边界比我以为的窄"。
- 不设计"内幕""颠覆"类标题承诺。
