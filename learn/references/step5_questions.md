# 第5步引导性问题模板

## 骨架搭建问题（5-7个）

每次执行第5步时，从以下问题库中选取5-7个最相关的提问。根据选题特点调整措辞。

### 核心定位类

1. **"这篇文章你最想表达的1个核心观点是什么？"**
   - 目的：锁定文章的灵魂，所有素材都围绕这一个观点展开

2. **"你的核心读者是谁？他们最需要从这篇文章获得什么？"**
   - 目的：确定读者画像，影响语气、深度、案例选择

3. **"结尾你想传达什么信念？"**
   - 目的：锚定结尾升华方向

### 结构策略类

4. **"你打算用什么开头？为什么读者会继续看下去？"**
   - 目的：确定开头hook策略（荒诞事实/个人经历/反常识/痛点直击）

5. **"正方论点里哪个最值得展开？反方里哪个必须回应？"**
   - 目的：确定正反竞奇在文章中的权重分配

6. **"奇的部分你想怎么穿插？开头还是中间还是结尾？"**
   - 目的：决定跨领域素材的位置——开头做hook、中间做文化升维、结尾做信念支撑

### 个人素材类

7. **"你有什么只有你才知道的真实经历可以用？"**
   - 目的：挖出独一无二的个人素材，这是文章活人感的核心来源

8. **"这个选题和你过去的哪段经历有关？"**
   - 目的：建立选题和作者之间的真实连接

### 竞品差异化类

9. **"别人写过类似的选题吗？你的文章和他们最大的不同是什么？"**
   - 目的：确保文章有独特价值，不是重复已有内容

10. **"竞品/案例里哪个最值得详细对比？为什么？"**
    - 目的：确定竞品段落的重点

## 评判标准

用户自由写完脉络+骨肉后，AI从以下维度评判：

1. **核心观点清晰度**：能否一句话说清楚这篇文章在说什么？
2. **逻辑完整性**：开头→中间→结尾是否有完整的逻辑链条？
3. **素材覆盖度**：正反竞奇×冰山的素材是否被合理分配到文章各段落？
4. **个人独特性**：是否有只有作者才能写的内容（经历/观点/洞察）？
5. **读者价值**：读完这篇文章，读者能获得什么明确的收获？

**评判结果**：
- 通过 → 自动衔接 wenxuan-writer 开始写长文
- 有缺口 → AI补充提问深化，用户回答后再评判
- 严重偏差 → AI指出问题并给出调整建议

## 用户输出→writer衔接

用户在第5步的输出（脉络+骨肉）直接作为 wenxuan-writer 的输入素材：

1. 用户的核心观点 → writer的文章灵魂
2. 用户的开头策略 → writer的开头类型选择
3. 用户选定的正/反/竞/奇展开方向 → writer的段落内容分配
4. 用户想传达的结尾信念 → writer的结尾锚点
5. 用户的个人经历素材 → writer的活人感素材
6. 选题学习包中的关键词/必学精选/数据 → writer的知识弹药

衔接方式：第5步评判通过后，AI自动加载 wenxuan-writer skill，将用户的输出+选题学习包内容一并注入writer的上下文。
